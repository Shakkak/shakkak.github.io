# Avatar assets

Place `avatar.jpg` here and set `SHOW_AVATAR = true` in `js/main.js` to display the profile photo.

## Flag

Place a flag image (e.g. `ir.svg`, `ir.png`) in the `flag/` subfolder.
To use it, add an `<img>` tag near the avatar in `index.html` pointing to `assets/avatar/flag/<filename>`.
